# Mangra Extensions

Official extensions repository for Mangra — the manga reader & translator app for iOS.

## Available Extensions

| Extension | Description | Version |
|-----------|-------------|---------|
| Komga | Connect to your self-hosted Komga manga server | 2.2 |
| Komga_2 | Secondary Komga server connection | 2.2 |

## How to Add

1. Open **Mangra** on your iPhone/iPad
2. Go to **Extensions** settings (gear icon)
3. Tap **Edit** then **+**
4. Paste this URL:
   ```
   https://x901.github.io/mangra-extensions/0.9/
   ```
5. Tap **Add to Mangra**

Or visit the [extensions page](https://x901.github.io/mangra-extensions/0.9/) and tap **Add to Mangra**.

## What is Komga?

[Komga](https://komga.org) is a free, open-source media server for your comics, manga, and magazines. Host your personal library and read it from anywhere using Mangra.

### Demo Server
